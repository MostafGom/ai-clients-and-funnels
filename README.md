# AI Clients & Funnels

A multi-client funnel studio: personas, per-client design systems, and five funnel types
(free ebook, calendar booking, VSL → call, VSL → checkout, checkout with upsell/downsell) on one
Astro site deployed to Cloudflare Workers. See `CLAUDE.md` for conventions and commands.

```
cd web && pnpm install && pnpm dev
```
