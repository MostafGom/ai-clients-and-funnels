# Blueprint: checkout (long-form sales page → checkout → upsell → downsell)

**Goal** — sell a product from a written sales page; same monetization stack as vsl-checkout.
**Pages** — `/` (sales page) → `/checkout` → `/upsell` → `/downsell` → `/thanks`

## Page `/` — sales page order
1. `Hero` (promise headline, mechanism subheadline, CTA → `#pricing`, proof line)
2. `Benefits` as **the problem** (3 pains, named precisely)
3. `Steps` as **the system** (how it works, with time)
4. `Testimonials` (results with numbers)
5. `PriceCard` × 1–2 in `#pricing` (anchor with compareAt; highlight the one you want sold)
6. `Guarantee`
7. `FAQ` (time, fit, access, payment plan)
8. `StickyCTA`
Copy: PAS or Story → Mechanism → Offer → Proof → Risk reversal → FAQ. Every section ends facing the CTA.

## `/checkout`, `/upsell`, `/downsell`, `/thanks`
Identical to vsl-checkout blueprint (share the same components and price keys).
