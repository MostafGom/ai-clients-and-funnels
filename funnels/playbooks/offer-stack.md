# Offer stack, pricing, bump / upsell / downsell

Value equation (Hormozi): value = (dream outcome × perceived likelihood) ÷ (time delay × effort). Every component of the offer should raise the top or shrink the bottom. Say which, in PLAN.md.

## The stack (sales page block 8)
| Item | Benefit line (why it's there) | Value |
|---|---|---|
| Core program | the outcome | $ |
| Tool / template | shrinks effort | $ |
| Fast-start | shrinks time delay | $ |
| Support / community | raises likelihood | $ |
| Bonus 1 | kills objection A | $ |
| Bonus 2 | kills objection B | $ |
| **Total** | | **$X** → price $Y |
Total value should be 3–5× price. Bonuses are named after the objection they kill.

## Anchors (in this order)
1. Total value of the stack. 2. Cost of the alternative (1:1 consultant, months of trial and error). 3. Cost of doing nothing (in the reader's currency: nights, evenings, sanity, marriage). Then the price.

## Order bump (checkout page)
Impulse price (≤ 10% of main). Solves the *next* problem they'll have after the main offer works. Copy = headline + 2–3 lines + "add for $X" checkbox. Pre-checked never.

## Upsell (one-click, after payment)
Bigger, faster, done-with-you version of the same outcome (coaching, implementation, speed). 40–100% of main price. Copy structure: "Your order is confirmed. One thing before you go." → why they're seeing it (honest: offered once, here) → what it is → 3–5 deliverables → the one objection it kills → price with anchor → Yes button (exact wording) → honest decline link.

## Downsell (after declining upsell)
Smaller, cheaper, or a payment plan of the upsell. Never a worse version of the main product. Frame: "Totally fine. Here's the lighter option." 20–50% of upsell.

## Thank-you page
One job: get them to use what they bought in the next 10 minutes. Next steps, what arrives when, one button.
